# Vending Machine Sale Predictions

This repository uses machine learning models such as Random Forest Classifier, Logistical Regression, and Decision Trees Classifier to identify vending machine item aspects that leads to a sucessful sale.

# Goals

The goal of this repository is to predict whether a vending machine item will be selected based on item attributes such as size and type as well as location attributes such as at the edge of the vending machine, at eye level, or the item's distance from the center. 

# Models

- Random Forest Classifier
- Logistical Regression
- Decision Trees Classifier

# Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC
- Mean predicted probability
